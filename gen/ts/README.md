# Generated TypeScript protobuf code

Generated `open_splunk` `ts-proto` messages for the Next.js application are
written under `open_splunk`, with generated barrel indexes in this tree. The
tree also includes the generated Google protobuf support types imported by
those messages. Git ignores the TypeScript output. Frontend builds regenerate
it from the schemas in `proto/` using the locked npm dependencies. To generate
it on its own, run `npm run proto:ts` from the repository root.
